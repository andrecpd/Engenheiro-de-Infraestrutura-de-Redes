# Python para NetOps

## Objetivos
- Automatizar coleta e normalização de dados.
- Validar prefixos e entradas de inventário.
- Gerar relatórios repetíveis e tratar erros.
- Evitar exposição de credenciais em logs.

Execute o exercício inicial com `python 06-python/validate_prefixes.py`. Ele valida prefixos IPv4/IPv6 e reporta sobreposições.

Use dados de exemplo e nunca inclua tokens, senhas ou inventários sensíveis.
